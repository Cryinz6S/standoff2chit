# OLL Aim Trainer (Android)

A standalone landscape Android touch-aim trainer. It does **not** access, inject into, or modify Standoff 2 or any other game.

## Features
- Tap-to-start practice round
- Randomly repositioned concentric targets
- Hits, shots, accuracy, current/best streak, elapsed time
- Tap the top-right timer area to cycle difficulty (easy / medium / hard)
- Android 6.0+ (minSdk 23)

## Build with GitHub Actions
1. Open the **Actions** tab.
2. Select **Build Android APK**.
3. Choose **Run workflow**.
4. When the run succeeds, open it and download the `OllAimTrainer-debug-apk` artifact.
5. Extract the downloaded ZIP to get `app-debug.apk`.

The APK is a debug build for personal testing, not a Play Store release.
